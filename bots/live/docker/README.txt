Needs Docker Desktop installed and running: https://www.docker.com/products/docker-desktop/

1. Unzip this folder anywhere.
2. Double-click start.bat (or run "docker compose up --build" in this folder).
   The first start builds everything and takes several minutes; later starts are quick.
3. When it prints "Your page: https://....trycloudflare.com", open that page, or send it to whoever wants to play.
   Pick the tanks and press Start. With a friend's seat in it, "Copy party link" in the waiting room gives the link
   they join by.

The address is new every time it starts, so send a fresh one after a restart.
The tunnel can take a minute to answer after the address shows up.
Close the window or press Ctrl+C to stop it.
